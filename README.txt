GNHS NUMERACY DRILL - MAC
=========================
Start screen: TEACHER (PIN, runs the drill) or STUDENT (type the teacher's address to join).
Data is saved in Documents/GNHS-Numeracy-Data. Forgot the PIN? Delete gnhs-pin.json there.

BUILD ON YOUR MACBOOK
  1. Install Python 3.12+ from python.org (the Apple Python 3.9 gives a blank window).
  2. Terminal:
       cd <this folder>
       xattr -cr .
       bash build_mac.command
  3. The app is in dist: GNHS Numeracy Drill.app  -> drag it to Applications.

(Or build it on GitHub: upload this folder, open Actions, download "Mac-app".)

USE
  First open: right-click the app > Open > Open, or:  xattr -cr "/Applications/GNHS Numeracy Drill.app"
  Same Wi-Fi as the students. Port 8000.
